# Situations: are they fair?

Each scenario was played 300 times with a league-average team on each side and the computer calling plays for you. A scenario passes if it is hard but winnable: you win between 10% and 90% of the time. Two are long shots by design (a Hail Mary and a 10-point comeback with 5 minutes left); those only need to be possible (at least 3%).

| Scenario | You win | Tie | You lose | Check |
|---|---|---|---|---|
| 2-minute drill | 21% | 0% | 79% | pass |
| Red zone offense | 64% | 0% | 36% | pass |
| Goal-line stand | 15% | 0% | 85% | pass |
| 4-minute offense | 78% | 0% | 22% | pass |
| Backed up | 58% | 0% | 42% | pass |
| 3rd & long | 17% | 0% | 83% | pass |
| 4th & 1 | 75% | 0% | 25% | pass |
| End-of-half Hail Mary | 8% | 0% | 92% | pass |
| Comeback | 3% | 4% | 93% | pass |
| Defend a 2-minute drill | 79% | 0% | 21% | pass |
| Overtime possession | 49% | 16% | 35% | pass |

Every scenario is winnable and none is a sure thing.
